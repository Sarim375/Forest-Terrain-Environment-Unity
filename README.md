# 🌲 Forest Terrain Environment - Unity 3D Showcase

![Platform](https://img.shields.io/badge/Platform-Windows-blue.svg)
![Type](https://img.shields.io/badge/Type-3D%20Environment-green.svg)

This repository contains a compiled standalone 3D simulation showcase of a Forest Terrain Environment built in Unity. The environment was developed as an academic assignment mapping practical techniques in terrain sculpting, foliage propagation, and high-fidelity environment assets.

---

## 🎨 Design Elements & Features

The environment consists of several core elements that combine to form a realistic forest ecosystem:

- **Custom Sculpted Terrain**: Hand-modeled heightmaps featuring ridges, slopes, and valleys to simulate a natural topography.
- **Dynamic Terrain Textures**: Seamless blending of multiple high-resolution textures (soil, meadow grass, and rocky cliff faces) depending on slope angle.
- **Foliage Density System**: Rich density propagation of natural assets including:
  - Oak and coniferous trees.
  - High-density wild grass patches.
  - Natural shrubbery.
- **Atmospheric Lighting**: Configured ambient directional lighting with realistic shadow casting to emulate realistic forest canopy light scatter.
